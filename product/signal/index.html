The PSS pipeline

  1. 50 traceable indicators

    Each carries a raw value, a percentile and a weight — 4–8 per pillar.

  2. 8 strength pillars

    Citation, legal, technical, market and four more, independently weighted.

  3. 0–100 objective score

    Percentile-ranked against the whole pool — one cross-industry benchmark.

  4. SABCD grade

    A discretisation of pool percentile. S is the top 15%.

How it works

  1. Submit

    Pick a report, add your input 10% deposit

    A patent number, a pending draft, or a description of the idea. A card deposit starts the work, and bad input is caught before it. You get a confirmation email carrying a retrieval code.

  2. Produce

    TIS produces your report

    We pull Innovue data, run the match, and write it up with AI. Hours to days, not weeks. We email you when it is ready; the report itself stays on the site.

  3. Retrieve

    Verify, preview, then download 90% balance

    Your email and code unlock a free outline of what every chapter covers, not excerpts. Settle the balance to download the watermarked PDF, retrievable forever with the same credentials.
