## 2. Core concept model

**The dual engine / triangle** — the reusable spine of the story (GP deck, 投影片 5; verbatim):

- 🟢 **AI（顯影劑）：** 以 Innovue（全球前四大專利資料庫，現由台積電使用）＋ AI 盤點，揭露每個標的的專利真空與侵權風險。
  *EN: AI (the developing agent): with Innovue (a top-4 global patent database, now used by TSMC) + AI audit, reveal each target's patent vacuum and infringement risk.*
- 🟢 **IP（護城河）：** 由 TIS 為被投公司布局高品質專利、加入共有專利池，築起競爭對手難以跨越的防護牆。
  *EN: IP (the moat): TIS files high-quality patents for portfolio companies and joins them to the shared pool, building a wall competitors can't cross.*
- 🟢 **VC（實施力）：** GP 以投資地位確保被投公司確實採用此套智權方案，把資本轉化為可衡量的價值提升。
  *EN: VC (execution power): as investor, the GP ensures portfolio companies actually adopt the IP program, converting capital into measurable value uplift.*
- 🟢 **投前避雷、投後築牆** *(recurring motto) — clear the mines before investing; build the wall after.*

## 4. Signature assets / differentiators (verbatim)

- 🟢 **Cross-License Commons（共有專利池）** — (GP 投影片 9) 被投公司彼此回授專利至共有池，池再自動授權給所有其他被投公司。 (Portfolio 投影片 6) 這是外部買不到、也帶不走的集體防禦力。越早加入，您分享到的池越大。
- 🟢 **台灣非紅供應鏈橋接** — (GP 投影片 10) 「美國（國際）資本 ＋ 台灣非紅製造 ＋ 乾淨 IP」是對國際買家與下游客戶的硬賣點。 策略夥伴：漢翔、台船、雷虎、智飛、新樂飛、中光電智能機器人、NCSIST、ITRI。
- 🟢 **Innovue IP Tech** — Innovue（全球前四大專利資料庫，現由台積電使用）；具英文版，支援美國市場對接。
- 🟢 **反向 NPE 立場** — (GP 投影片 5) 與一般 NPE 的反向定位：我們不主動興訟——IP 是用來保護被投公司、提升其價值，不是用來打官司。
